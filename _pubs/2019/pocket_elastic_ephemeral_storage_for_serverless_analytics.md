Pocket is a fast, elastic, fully managed cloud storage service for sharing intermediate data in serverless analytics applications. It combines multiple storage technologies, rightsizes resources for each job, and scales capacity automatically. Pocket delivers performance comparable to an in-memory datastore while providing fine-grained elasticity and lower cost.
