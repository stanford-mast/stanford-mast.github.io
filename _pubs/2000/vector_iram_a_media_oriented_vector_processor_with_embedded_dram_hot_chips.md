Vector IRAM combines vector processing with embedded DRAM to provide high multimedia performance with low power consumption and reduced design complexity. This Hot Chips presentation describes the prototype's vector instruction set, 256-bit vector unit, 16 MB on-chip DRAM system, modular implementation, compiler support, and performance and energy characteristics.
