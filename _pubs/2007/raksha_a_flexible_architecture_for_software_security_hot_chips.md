Raksha is a flexible hardware-software architecture for dynamic information-flow tracking. This Hot Chips presentation describes programmable security policies, simultaneous enforcement of multiple policies, low-overhead software handlers, and an FPGA prototype that detects both low-level memory-corruption attacks and high-level semantic attacks.
